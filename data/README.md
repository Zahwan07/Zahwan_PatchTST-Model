# Data for PatchTST plant growth prediction

**Target crop:** Red leaf lettuce (*Lactuca sativa* L.). See **lettuce_reference.md** for optimal soil moisture and pH.

## Pipeline overview

1. **Build training input** – `build_internet_data.py` combines:
   - **fetch_bmkg_coblong.py** → weather & temperature (Coblong, Bandung)
   - **generate_lettuce_data.py** → soil moisture & pH (optimal for lettuce)  
   → writes **internet_data.csv**

2. **Dummy realtime** – When you don’t have live sensors, `build_internet_data.py` also writes **realtime_data.csv** with dummy rows for the prediction step.

3. **Training** – `fusion.py` merges internet_data + realtime_data → preprocess → train PatchTST.

4. **Prediction** – Last `INPUT_LEN` rows of **realtime_data.csv** (dummy or real) → PatchTST → **7-day environment forecast** (temperature, weather, soil moisture, pH). The numeric forecast is then sent to an **LLM API** to produce natural-language recommendations (e.g. “Weather will likely stay 23°C for 2 days; expect soil moisture to reduce…”).

## Required CSV columns

All CSVs use these 4 columns:

| Column       | Meaning            | Example / units |
|-------------|--------------------|------------------|
| `suhu`      | Temperature        | °C (e.g. 25.5)   |
| `cuaca`     | Weather            | 0=cerah, 1=berawan, 2=hujan |
| `kelembapan`| Soil moisture      | 0–1 (e.g. 0.55–0.60 optimal for lettuce) |
| `ph`        | Soil/substrate pH  | 6.0–7.0 optimal for lettuce (e.g. 6.5) |

## Files

- **internet_data.csv** – Produced by `build_internet_data.py` (BMKG + lettuce). Used with realtime_data in `fusion.py` for training.
- **realtime_data.csv** – Dummy data from `build_internet_data.py` when no sensors; used as the input window for prediction.
- **bmkg_coblong.csv** – Optional; filled by `fetch_bmkg_coblong.py` and read by `build_internet_data.py`.
- **lettuce_reference_data.csv** – Generated by `generate_lettuce_data.py`; read by `build_internet_data.py` for kelembapan & ph.

## Commands (from project root)

```bash
# 1. Build internet_data (BMKG + lettuce) and dummy realtime_data
python build_internet_data.py

# 2. Train (fusion merges internet + realtime, then trains PatchTST)
python train.py

# 3. Predict: 7-day forecast + LLM recommendations
python predict.py
```

## LLM recommendations (optional)

To get AI-generated advice from the 7-day forecast, set one of:

- **OPENAI_API_KEY** – OpenAI API key (uses `gpt-4o-mini` by default).
- **LLM_API_KEY** + **LLM_API_BASE** – For an OpenAI-compatible endpoint.
- **LLM_MODEL** – Model name (default `gpt-4o-mini`).

If no key is set, `predict.py` still prints the numeric forecast; it will only skip the LLM step.
